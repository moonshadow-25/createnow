## 🆕 video_prompt 强制格式（以下规范覆盖所有旧格式，必须严格执行）
Seedance 2.0 视频提示词应用规范 (V2.0)
一、 核心提示词公式：5 段式结构
为了确保生成的视频具有“导演级”的可控性，每一条提示词应遵循以下结构：

 [@引用标签]+[主体角色] + [核心动作] + [镜头语言] + [环境光影与风格]
引用标签 (@References)：这是 Seedance 2.0 的核心。通过 @图N 锁定角色/场景图片，通过 @音频N 绑定角色声音（仅「有音色=是」的角色才有 @音频N 可用）。
主体角色 (Subject)：详细描述角色的年龄、着装、材质（如：一位穿着磨损皮革夹克的青年，面部有细微汗水）。
核心动作 (Action)：使用现在进行时，明确动作的幅度与频率。建议每 5-10 秒只描述一个主动作。
镜头语言 (Camera)：明确景别（Wide, Medium, Close-up）和运动轨迹（Dolly-in, Pan, Orbit）。建议标注镜头焦距（如 35mm, 85mm）。
环境与风格 (Environment & Style)：描述光影性质（软光、逆光、丁达尔效应）和画面风格（胶片质感、废土工业风、2K 高清），与上下文中的“全局风格”对应。


二、强制分片：总长≤≤15秒：输出 1 个 Segment。总长 16-30秒：输出 2 个 Segment。总长 31秒以上：依此类推。视觉桥梁锁死：强制执行Segment [N].Shot 1 = Segment [N-1].Shot 5的视觉参数同步。矩阵生成：严格执行“3秒一跳/5段矩阵”格式，确保每一段 100% 独立。视觉保戏：在 Segment [N] 的 Shot 1，必须复述 Segment [N-1] 的 Shot 5 结尾状态。3. 输出规范与标准格式 (Output Standard)[必须遵循的结构要求]：每一段 15 秒提示词必须包含以下四个完整模块：核心剧情摘要：一句话说明本段内容。资产映射 (Asset Definitions)：全量列出本次生成调用的所有 @image 标签。全局风格 (Global Style)：定义画质、光影、相机策略。5段式分镜矩阵 (Matrix Script)：分 5 个 Shot，每个 Shot 包含：【主体动作】、【物理细节】、【镜头语言】。原生视听 (Native Audio)：含对白全文标注 [Lip-sync] 及环境音。
此外，分片最重要的因素是对白（包括OS）的字数（不含动作描写/镜头语言）：
- 台词必须直接使用当前分镜对应的剧本原文，不得扩写、改写、缩短或截断。
- 当对白较少时，可用反应镜头、动作镜头、环境镜头补足画面节奏，但不得新增剧本中不存在的台词。


三、正确范例：
[Segment] 荷尔蒙冲击与初次交锋

[Asset Definitions]

@音频1 (Ray 的声音)   ← 仅当角色有音色时才声明

色调：高反差、硬朗。阳光像聚光灯一样打在 Ray 的肌肉上，形成强烈的丁达尔效应，金质名片的高光与背景废墟的锈迹形成暴力美学对比。
运镜策略：极慢速动作 (Ultra-slow motion) 与视觉冲击力的特写切换，强化感官刺激。

[Director's 5-Shot Matrix Script]

Shot 5 (12-15s):
主体动作: @图1 Ray 漫不经心地保持着咬住衣角的姿势，嘴角带笑。[Lip-sync] 眼神极其松弛，完全无视对方的震惊。

### 🔑 全局风格注入规则：
- 在所有 @图N 引用之后，立即插入全局风格描述（从上下文 `【全局视频风格】` 中获取）
- 若全局风格为空，跳过此步骤
- 全局风格是画面基调，必须出现，但不能影响后续镜头语言和对白

### ⚠️🔑 音频引用规则（强制执行，每次生成分镜必须检查）：
- **第一步**：查看上下文中的【可用资产】列表，找出所有标注「有音色=是」的角色
- **第二步**：若有音色角色，在 [Asset Definitions] 中按出现顺序声明：`@音频1 (角色名的声音)`
- **第三步**：在 video_prompt 末尾（严禁字幕行之前）加一行：`@音频1是角色名的声音，@音频2是角色名的声音`
- @音频N 的编号顺序 = 该分镜 character_ids 中「有音色=是」的角色出现顺序
- 若所有角色均无音色，跳过此步骤

### 🔑 正反打场景处理规则（强制执行）：
- 若场景名称含有「后视」「反打」「背面」「背视」「反向」「反转」等字样，说明存在正反打场景对。**正打和反打场景必须都在分镜矩阵中被引用，禁止只用其中一个而闲置另一个**
- 分镜描述中若明确写明了某角色以哪个场景为背景（如"以杏花村酒坊门口为背景"），必须严格按描述使用对应的 @图N
- 分镜描述未明确指定时，根据剧情自动判断：面向同一方向的角色共用正打场景，面向相反方向的角色使用反打场景
- **角色-背景绑定**：一旦确定，同一角色在所有 Shot 中的背景 @图N 必须保持不变。拍摄角色A时用A的绑定场景，拍摄角色B时切换到B的绑定场景，禁止串用

### 🔑 对白规则（最高优先级，绝对不可违反）：
- ⚠️ 必须使用剧本中的**原文台词**，一字不改、不缩短、不意译、不总结
- 格式：`角色名说："原文台词"`
- 如果一段对白超过15秒，按照剧本中的自然停顿点拆分到多个分镜，每个分镜仍各自保持原文
- 绝对禁止：将"草民无万夫不当之勇，却有定国安邦之毒计。"改写成"草民有计谋"——这是不可接受的

### 🔑 固定结尾（每个video_prompt必须以此结束，不可省略）：
```
严禁任何字幕，严禁背景音乐
```

### 镜头语言词汇库（每个分镜至少选用2种）：
**运镜**：跟拍 / 推近 / 拉远 / 环绕360° / 摇镜 / 升降镜 / 希区柯克变焦 / 一镜到底 / 手持抖动 / 急速推近 / 主观视角
**景别**：特写 / 大特写 / 近景 / 中景 / 全景 / 大全景 / 俯拍 / 低机位仰拍 / 鱼眼镜头
**光影**：侧逆光勾边 / 丁达尔光柱 / 夕阳金光倾斜 / 室内顶光 / 霓虹冷光反射 / 烛光暖调 / 逆光剪影
**节奏**：快速闪切 / 慢动作升格 / 定格特写 / 时间停顿 / 镜头抖动冲击感


### ❌ 绝对禁止的写法：
- ❌ "角色在场景中说话，镜头推近" —— 太简单，无镜头语言
- ❌ "高阳说他有计谋" —— 篡改对白，原文是"草民无万夫不当之勇，却有定国安邦之毒计。"
- ❌ 结尾没有"透明度为0的字幕，严禁背景音乐"
- ❌ 全局风格放在最后而不是@引用之后
- ❌ 每个分镜的对白超过原文，添加剧本中没有的台词
- ❌ 角色有音色时，忘记在 [Asset Definitions] 声明 @音频N 并在 video_prompt 末尾注明
