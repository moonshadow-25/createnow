## 分镜图生图提示词格式规范（对话AI默认版 · 九宫格剧情）

为分镜的 `image_prompt` 字段写一段描述**完整九宫格（3×3共9帧）**的图生图提示词。
一条 `image_prompt` = 描述全部9帧，保存到该分镜卡片里。

### 引用参考图规则

- 使用"图1中的男人"/"图2中的女人"/"图3中的场景"格式，**不要用角色名**（图像API无法识别名字）
- 严禁自行描述人物衣着、场景布景——所有视觉资产必须直接继承参考图

### 核心原则

- 9帧之间景别必须跳跃，**严禁连续两帧出现相似角度**
- 融入项目全局图片风格
- 电影级氛围：高清、胶片质感、构图美学
- 不写字幕、不写旁白

### 九宫格结构

**第一排：场景建立**
- 第1帧 [远景/环境]：建立空间感，角色入场
- 第2帧 [中景]：角色关系/位置，人物互动
- 第3帧 [近景/特写]：表情或关键道具，情绪铺垫

**第二排：剧情推进**
- 第4帧 [特写]：情绪高点，戏剧张力
- 第5帧 [过肩]：对话视角，角色关系
- 第6帧 [中景/反应]：情绪变化，推进冲突

**第三排：情节高潮**
- 第7帧 [特写]：情绪爆发或关键细节，最强戏剧点
- 第8帧 [中景/动作]：动作或转折，情节推进
- 第9帧 [全景/收尾]：场景收尾，情绪沉淀

### 输出格式

`image_prompt` 字段值为包含全部9帧的完整文本，格式如下：

```
[全局图片风格]，九宫格剧情分镜

第一排：场景建立
第1帧 [远景/环境]：图N中的[角色]，[场景描述]，[光线/氛围]，画面无字幕
第2帧 [中景]：图N中的[角色]，[互动描述]，[光线/氛围]，画面无字幕
第3帧 [近景/特写]：图N中的[角色]，[表情/细节]，画面无字幕

第二排：剧情推进
第4帧 [特写]：...
第5帧 [过肩]：...
第6帧 [中景/反应]：...

第三排：情节高潮
第7帧 [特写]：...
第8帧 [中景/动作]：...
第9帧 [全景/收尾]：...
```

### 示例（国风古装悬疑）

```
国风古装仙侠质感，电影级写实，九宫格剧情分镜

第一排：场景建立
第1帧 [远景/环境]：图3中的瑞和院厅堂全景，廊柱林立，暮色中朱红灯笼排排高悬，夕阳斜光从廊外穿入，冷暖交织，画面无字幕
第2帧 [中景]：图1中的男子与图2中的女子相对而立于厅堂中央，两人之间距离隐含张力，烛光映照，画面无字幕
第3帧 [近景/特写]：图1中的男子面部近景，眉峰微锁，目光深沉落在某处，侧逆光勾边，画面无字幕

第二排：剧情推进
第4帧 [特写]：图2中的女子眼眸特写，眼底含着未言说的情绪，睫毛轻颤，暖光晕染，画面无字幕
第5帧 [过肩]：从图1男子肩后拍向图2女子，女子抬头对视，背景虚化为灯笼余晖，画面无字幕
第6帧 [中景/反应]：图2中的女子侧身转头欲离，图1男子伸手未触，定格动作，冷光从左侧照入，画面无字幕

第三排：情节高潮
第7帧 [特写]：两双手极近距离对峙，近乎相触而未触，光影交错强烈，画面无字幕
第8帧 [中景/动作]：图1男子快步上前，衣袂带风，图3厅堂景深中灯笼随之轻晃，动感构图，画面无字幕
第9帧 [全景/收尾]：厅堂空景，两人身影拉远，朱红灯笼在景深中延伸，氛围沉郁悠长，画面无字幕
```
